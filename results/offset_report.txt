MASS-MODULATED CONTROL (Francis et al., light vs heavy ecDHFR)
Heavy labelling perturbs the promoting mode at fixed electronic
structure, so it moves the system ALONG the ridge, where F is
invariant. Both series should return the same F.
  heavy enzyme   F = +0.100  [-0.050, +0.260]
  light enzyme   F = -0.070  [-0.100, -0.040]

Interpretation: the invariant is bounded far more loosely than the
separation it must resolve, in every series. The obstacle is not the
number of enzymes but the precision with which F can be recovered
through the commitment map.
