CHECK 3: dimensions of A and w
============================================================================
kappa = sqrt(k_f)/(2 hbar):  [k_f]=M T^-2, [hbar]=M L^2 T^-1
  => [kappa] = M^(1/2) T^-1 / (M L^2 T^-1) = M^(-1/2) L^-2
  so A = kappa R0^2 carries M^(-1/2): NOT dimensionless.
  correct: A = kappa sqrt(m_H) R0^2,  w = 2 kappa sqrt(m_H) sigma^2.

============================================================================
CHECK 4: mass-convention consistency
============================================================================
mass numbers 1,2,3          : gamma_SC = 3.257253
atomic masses               : gamma_SC = 3.262807
C-H/C-D/C-T reduced masses  : gamma_SC = 3.348866
The supremum identity holds in whatever masses are used, so the tunneling
supremum EQUALS gamma_SC in the same convention.  Comparing a model
evaluated with one set of masses against gamma_SC from another mixes
conventions and manufactures a gap.
